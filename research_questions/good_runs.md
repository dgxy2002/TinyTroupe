# Good runs: culture mentioned and resolved

Runs where a key agent linked a need to their culture and the conflict was resolved. All are Gemini 2.5
Pro, type 3 (culture in both persona and situation, linked explicitly), single runs. Paths are relative to
`research_questions/outputs/`. Each `.md` transcript has a matching `.json` file in the same folder with
the agents' private thoughts. Debriefs are in the run folder's `debriefs/`.

Two runs share the file name `S46-HW1-R01.md`, so always quote the folder as well.

## Qualifying cases

These meet definition B, in its supplied-need form: D raised the need, linked it to their background in
speech, thought or debrief, the agreement covers it, and D accepted it.

## Adding a run

Add a row only when both hold. Culture: the key agent links the need to their faith or background in
speech, thought or debrief. Resolved: the evaluator rates it resolved, or partly resolved with that need
settled. Check the deal is physically possible before adding it; the evaluator does not.
