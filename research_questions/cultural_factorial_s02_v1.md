# S02 label/name factorial screen

The four-cell screen ran one six-interval replication per cell using the earlier
latent-conflict S02 scenario:

| Cell | Explicit cultural labels | Associated names | Status | Peak | Final remaining | Substance |
|---|---|---|---|---:|---:|---:|
| F00 | no | no | partially resolved | 4 | 2 | 3 |
| F10 | yes | no | partially resolved | 3 | 2 | 3 |
| F01 | no | yes | no conflict | 0 | 0 | 3 |
| F11 | yes | yes | no conflict | 0 | 0 | 4 |

Names were replaced with Agent A-D in evaluator input. The agents themselves saw
the assigned names and, in F10/F11, the explicit `cultural_background` persona
field. Grounding was 5 and naturalness 4 in all four cells.

The two neutral-name cells happened to produce conflict while both associated-name
cells did not. This is not evidence of a name or cultural effect: there was only
one replication per cell, the dialogue mechanisms differed, and F10 had one
overlength retry plus two framework-suppressed repeated actions. The screen is a
pipeline check and a reason to replicate, not an inferential result.

The later explicit-conflict redesign changes the S02 scenario itself. Its outputs
must not be pooled with this factorial batch.
